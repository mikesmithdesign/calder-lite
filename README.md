# Erin Calder Lite: free one-page template for photographers

A single-file HTML template for a photographer portfolio: a full-bleed hero
with a poster-scale serif name, a selected-work grid, an about section, and a
contact band. Smooth scrolling (Lenis) and scroll-triggered reveals. No build
step, no frameworks. Open `index.html` and edit.

**Live demo:** https://calder-lite.vercel.app

## Quick start

1. Edit the text directly in `index.html`: name, standfirst, bio, contact details.
2. Replace the photos in `img/` with your own (keep the filenames, or update the `src` paths).
3. Point the contact links (`mailto:`, `tel:`, Instagram) at your own details.
4. Upload anywhere. It's static files. Vercel, Netlify and GitHub Pages host it free.
